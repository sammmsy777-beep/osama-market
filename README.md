# Osama Market

نسخة تطبيق Electron بقاعدة SQLite دائمة.

## التشغيل

```powershell
npm install
npm start
```

قاعدة البيانات تحفظ تلقائيًا في مجلد بيانات التطبيق باسم `osama-market.sqlite3`. بيانات الدخول الافتراضية بعد أول تشغيل:

- المالك: `owner` / `1234`
- أمين الصندوق: `cashier` / `1111`

## ما تم تنفيذه

- SQLite دائم مع Foreign Keys وفهارس.
- معاملات ذرية للبيع والشراء والمرتجعات والدفعات والمصاريف.
- تحديث المخزون وحركاته.
- الصندوق والديون والعملاء والموردون.
- صلاحيات المالك وأمين الصندوق.
- سجل تدقيق.
- نسخ واستعادة ملف قاعدة البيانات.
- واجهة عربية RTL.
